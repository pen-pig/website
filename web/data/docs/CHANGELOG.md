# 更新日志（CHANGELOG）

本页渲染于首页底部「更新日志」卡片，编辑 `data/docs/CHANGELOG.md` 后刷新页面即可生效。

## v1.5 — 2026-09-28

### 新功能：自建 OJ 训练平台
- **在线判题**：提交 C++14 / C11 代码，自动编译并逐测试点运行，判 AC / WA / TLE / RE / CE，按通过比例给分。
- **题库 152 题**（全部自带测试数据，自动评测）：
  - 《浅入浅出》基础题 100 道（入门IO / 分支 / 循环 / 数组 / 字符串 / 递归 / 数学 / 算法）；
  - CSP-J 2019–2023 复赛真题 20 道、CSP-S 2019–2023 复赛真题 16 道（考点改编练习版）；
  - GESP C++ 2023-09 / 2024-03 1~4 级编程题 16 道。
- **题目页**：题面（Markdown）、标签、样例、提交框、我的提交记录；列表页支持来源 / 难度 / 关键词过滤，已通过题目标绿。
- **后台管理**：人工判题队列（干事及以上）、题目编辑与测试数据增删（管理员）。
- **一键启动**：根目录 `start.bat`，双击启动本地服务器（自动探测 php.exe、检测 g++）。

## v1.4 — 2026-09-27

### 新功能
- **代码分享**：在线贴代码片段（18 种语言），highlight.js 高亮 + 行号 + 一键复制，作者可管理自己的片段。
- **站内搜索增强**：新增类型过滤（通知/项目/工具/网盘/代码分享），代码分享纳入搜索范围。
- **邀请码注册**：管理员生成带有效期的一次性邀请码，访客凭码 + 验证码自助注册。
- **个人头像**：上传头像（自动校验尺寸格式），首页与个人中心展示。
- **每日签到**：连续/累计天数统计 + 签到排行 Top10。
- **代码高亮**：Markdown 代码块支持 ```语言 标签，全站 highlight.js 11.9 本地化渲染。
- **在线代码预览**：资料/作业/通知附件中的代码文件免下载直接查看（行号 + 高亮，≤1MB）。
- **网盘整理**：文件改名、跨文件夹移动。
- **数据备份**：后台一键打包下载整个 data/ 目录（ZipArchive）。
- **操作日志**：关键操作留痕（保留 500 条，后台可查）。
- **私信删除**：收件人可删除收到的私信。

### 安全加固
- 登录失败锁定：连续 5 次失败锁 10 分钟，关键操作记录日志。
- router.php 路径穿越修复（realpath 边界校验）。
- 工具上传文件名规范化（拒绝路径分隔符与特殊字符）。
- 图形验证码 10 分钟时效 + 大小写不敏感。

## v1.3 — 2026-09-26

### 界面与体验
- **背景图修复**：壁纸此前被背景渐变层完全遮挡（默认图/个人上传图均不显示），现已正确叠加在光斑之下、渐变兜底之上，上传与更换立即生效。
- **Markdown 编辑器内联化**：编辑 Markdown 不再跳转独立页面，改为页内模态（左编辑 / 右实时预览、工具栏、字数统计、ESC 关闭），保存直接写回原表单。
- **文件选择按钮美化**：全站上传控件（网盘、作业、附件、头像、背景图等）统一玻璃化 + 主色「选择文件」按钮，悬停反馈与全站一致。
- **裸排页面收编**：「插件工具」「问卷投票」「项目与资料」页头统一包进玻璃卡片，风格与全站一致。
- **关于本站**：新增「README · 站点说明」与「更新日志」展示页，导航直达，访客可见。
