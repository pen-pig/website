# 社团官网 · 站点说明（README）

一个面向学校编程社团的轻量级官网系统：PHP + JSON 文件存储，无需数据库，部署简单。

## 功能一览

| 模块 | 说明 |
|---|---|
| 通知公告 | 对外公告（访客可见）+ 内部通知（登录可见、已读标记） |
| 项目与资料 | 分支 → 小项目两级结构，资料下载、作业提交、优秀作业展示 |
| 代码预览 | 附件中的代码文件（c/py/js/php 等）在线高亮查看，免下载 |
| 代码分享 | 在线贴代码片段，语法高亮 + 一键复制，站内可搜索 |
| 网盘 | 全站共享网盘，文件夹树浏览、批量上传、改名/移动、20G 限额 |
| 膜拜 | 社团互动页：对象展示 + 每日幸运值 + 排行榜 |
| 问卷投票 | 单选/多选/填空题、匿名或实名、截止时间 |
| 插件工具 | 上传 .html/.php 小工具，站内 iframe 直接打开 |
| 私信 | 站内私信，30 秒未读数轮询，收件可删除 |
| 注册 / 签到 | 邀请码自助注册；每日签到 + 连续天数 + 排行榜 |
| OJ 训练 | 自建在线判题：152 道题（基础 100 + CSP-J/S 36 + GESP 16），C++14/C11 提交，自动编译判 AC/WA/TLE/RE/CE |
| 搜索 | 通知 / 项目 / 工具 / 网盘 / 代码分享全文搜索，类型过滤 |
| 个性化 | 每人可自定义主题色与背景图，个人覆盖站点默认 |

## 快速上手

1. 索取账号（管理员/干事/成员/游客）或向管理员要**邀请码**，在登录页「凭邀请码注册」自助开通。
2. 登录后进入「我的 → 个人中心」，可改密码、换头像、换主题。
3. 「项目与资料」里交作业；「代码分享」贴代码；「网盘」存共享文件；「问卷」参与投票。
4. 「OJ 训练」刷题：选题 → 写 C++14/C11 代码 → 提交，系统自动编译并按测试点给分。

## 主题自定义

- **站点级**：管理员在「后台管理 → 网站设置」设置主色调与默认背景图。
- **个人级**：登录后「个人中心 → 个人主题」上传自己的背景图（jpg/png/gif/webp，≤5MB）、选择主色，立即生效；「恢复默认主题」一键还原。

## 技术说明

- 服务端：PHP 5.6+（兼容 PHP 8.x），无数据库依赖。
- 数据：`data/json/*.json` 文件 + `data/uploads/` 上传目录（生产环境应在 web 根之外）。
- 前端：Bootstrap 4.6 + jQuery 3.5 + highlight.js 11.9（均已本地化，无 CDN 外链依赖）。
- 安全：bcrypt 密码、CSRF 校验、会话固定防护、图形验证码、登录失败锁定、上传扩展名白名单、操作日志留痕。
- 运维：后台「数据备份」一键打包 data/；关键操作写入操作日志。
